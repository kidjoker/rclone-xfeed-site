Personal-use utility

rclone-xfeed

rclone-xfeed is a personal-use Google Drive connection configured for use with rclone, an open-source file management and synchronization tool.

What it does

After the Google account holder grants permission through Google's OAuth consent flow, this configuration allows rclone to access that account's Google Drive files for user-initiated operations such as listing, copying, uploading, downloading, and synchronizing files.

Who it is for

This application is intended for the owner's personal use. It is not offered as a public file hosting service and does not provide access to anyone's Google Drive without that account holder's authorization.

Privacy and control

  • Google Drive access requires the account holder's authorization.
  • Access can be revoked at any time from the Google Account security settings.
  • File transfers are initiated and configured by the account holder through rclone.

For more information about what data is accessed and how it is handled, read the Privacy Policy.
